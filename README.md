# Fotografia
 Projeto de website desenvolvido para a Marília Manzatto Furlan – Foto e Vídeo, com o objetivo de apresentar seus trabalhos, serviços e portfólio de forma profissional e moderna.  O site foi pensado para proporcionar uma experiência simples e intuitiva aos visitantes, destacando fotografias, vídeos, informações sobre os serviços e formas de contato.
